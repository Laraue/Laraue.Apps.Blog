Laraue Boards предоставляет удалённый **MCP** (Model Context Protocol) сервер, поэтому AI-агент вроде Claude может работать с вашими issues напрямую — просматривать их, открывать конкретный issue, переносить его между статусами или оставлять комментарий — без переноса данных вручную.

## Что понадобится

[API-ключ](/ru/blog/documentation/laraue-boards/integrations/api-keys) для организации, к которой должен получить доступ Claude. Создайте его на странице **Account → API keys** перед подключением.

## Подключение в Claude

В Claude введите `/mcp`, чтобы открыть список MCP-коннекторов, выберите там вариант **custom connector** и добавьте:

- **URL**: `https://boards.laraue.com/boards-mcp/mcp`
- **Заголовок**: `X-Api-Key` со значением вашего API-ключа

![Добавление MCP-коннектора Laraue Boards в Claude: URL сервера и заголовок X-Api-Key](https://laraue.com/static/images/blog/docs/laraue-boards/claude-mcp-connector-setup.jpg)

Laraue Boards также размещён в [официальном реестре MCP](https://registry.modelcontextprotocol.io) под именем `com.laraue/boards`, поэтому любой другой MCP-совместимый клиент, умеющий искать в реестре, найдёт его так же.

## Что умеет Claude

Каждое действие выполняется с вашими собственными правами, в реальном времени — Claude не может сделать в организации то, что не могли бы сделать вы сами, и не может действовать вовсе, если API-ключ за ним отозван.

- **Issues** — просматривать и фильтровать issues, открывать один из них полностью, создавать новый, редактировать содержимое или исполнителя, переносить в другой статус или удалять
- **Комментарии** — добавить комментарий к issue или отредактировать свой
- **Структура организации** — смотреть спейсы, статусы, кастомные атрибуты и участников, чтобы Claude мог сам сопоставлять названия с нужными id
- **Вложения** — скачать изображение, приложенное к issue

Claude предлагает только те действия, которые вам реально разрешены — например, не предложит удалить issue в спейсе, где у вас нет права на удаление.

## Отзыв доступа

Доступ полностью привязан к API-ключу. Отзовите его на странице **Account → API keys** в любой момент — и Claude сразу теряет возможность обращаться к этой организации, точно так же, как при отзыве любого другого ключа.
